# Nangni Insight · Emission Watch

**가스터빈 NOₓ 배출 데이터 조사 보조 프로토타입**

공개 가스터빈 운전 기록으로 학습한 모델의 NOₓ 예측값을 실제 측정값과 비교하고, 비슷한 2013년 운전 기록을 찾아 추가 조사에 쓸 단서를 제공합니다. **설비 고장 탐지기, 환경 규제 준수 판정기, 실제 발전소용 검증 완료 예측기는 아닙니다.**

## 사용 방법

1. Streamlit 앱의 **CSV 업로드 · 내 기록 조사**에서 2014년 예시 CSV를 다운로드합니다.
2. 그 CSV를 업로드해 예측 NOₓ, 실제 NOₓ(제공된 경우), 예측오차와 비교 가능/보류 기록을 확인합니다.
3. 업로드 행 번호를 선택해 가장 가까운 2013년 기록, 표준화 거리, 과거 NOₓ를 살펴봅니다. 결과 CSV를 내려받을 수 있습니다.

필수 열: `AT, AP, AH, AFDP, GTEP, TIT, TAT, TEY, CDP`. 선택 열: 실제 측정값 `NOX`. 입력은 원본 UCI 자료와 동일한 변수 정의와 단위를 사용해야 합니다. CSV는 UTF-8, 최대 10 MB 및 20,000행입니다. 실제 NOX 열이 없으면 예측오차는 계산하지 않습니다. 공개 데모에 민감한 설비 정보나 개인정보를 업로드하지 마세요.

**비교 가능**은 과거 운전 변수와의 *탐색용 표준화 거리*가 임시 기준 안에 든다는 뜻입니다. **비교 보류**는 이 기준에 맞는 참조 기록이 없다는 뜻입니다. 어느 쪽도 정상/고장 판정이 아닙니다. 2014년 예시 5행은 비교 기준인 2013년 자료를 그대로 복제하지 않았으며, 2행이 비교 가능하고 3행이 보류입니다.

## 모델 및 평가

- 데이터 출처: [UCI Gas Turbine CO and NOx Emission Data Set](https://archive.ics.uci.edu/dataset/551/gas+turbine+co+and+nox+emission+data+set) (2011~2015년 공개 기록).
- 모델: 2011~2012년 운전 변수 9개로 학습한 `HistGradientBoostingRegressor`. NOX를 목표값으로 예측합니다.
- 동일 모델의 연도별 평가 (단위: MAE는 mg/m³):

| 평가 연도 | MAE | R² | 평균 오차(실제−예측) mg/m³ | 용도 |
| --- | ---: | ---: | ---: | --- |
| 2013 | 5.747 | 0.584 | +1.609 | 검증 |
| 2014 | 9.712 | -0.278 | -8.423 | 탐색/시연 |
| 2015 | 12.017 | -0.466 | -11.907 | 별도 최종 평가, 7,384건 |

2015년 결과는 **모델 재학습 없이** 측정했습니다. 상세 수치와 출처는 [`evaluation_2015_results.json`](evaluation_2015_results.json) 및 [GitHub Actions 평가 기록](https://github.com/lovingnangni/emission-watch/actions/runs/35186995776)을 참고하세요. 다른 연도에서 예측이 불안정하므로 이 모델을 다른 설비에 그대로 적용했을 때의 정확도는 보장되지 않습니다.

## 개발 범위와 한계

- 과거 공개자료 기반, 파일 단위의 탐색적 분석입니다. 실시간 센서 연결, 실제 고장 레이블, 고장 원인 진단, 배출 저감 효과 검증은 포함하지 않습니다.
- 유사 기록 검색은 조사에 도움이 되는 비교 사례를 제시하지만, 과거 데이터 자체가 모두 정상 운전임을 보장하지 않습니다.
- CSV 업로드는 페이지에서 분석하며, 앱의 데이터베이스에 저장하는 기능은 없습니다. 다만 공개 배포 서버에 민감한 자료를 보내지 마세요.
- 현재 저장소는 iPad 업로드를 위해 모델·자료·기존 앱 코드를 `emission_watch_ipad_upload.zip`으로 묶어 두고 `app.py`에서 검증 후 로드합니다. 배포 실행 파일은 저장소 최상단의 `app.py`입니다.
